# toshibat1100-memexp
Toshiba T1100 laptop is the fist laptop from Toshiba and one of the first laptops in the world. It had 256KB memory included and there was possiblility to upgrade it to 512KB by adding a memory explansion board. This project represent a custom made memory expansion board based on original schematics. The schematic is taken by reverse engineering the original Toshiba T1100 memory expansion.
